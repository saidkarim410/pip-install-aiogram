# Mechanica — индустриальный аддон в стиле Create для Minecraft Bedrock 1.21.x

Готовый файл: **`dist/Mechanica.mcaddon`** (behavior pack + resource pack, скрипты на Script API).

## Установка
1. Скачайте `dist/Mechanica.mcaddon` и откройте его — Minecraft импортирует оба пака.
2. Создайте мир (или откройте существующий) и подключите **Mechanica** в разделах «Пакеты ресурсов» и «Пакеты поведения».
3. Экспериментальные функции включать не нужно. Минимальная версия игры — 1.21.30.

## Что внутри

### Кинетика (вращение, как в Create)
| Блок | Что делает |
|---|---|
| **Вал** | передаёт вращение по своей оси |
| **Шестерня / Большая шестерня** | передают вращение соседним шестерням в одной плоскости; большая ↔ малая меняют скорость в 2 раза |
| **Водяное колесо** | источник: 8 об/мин у текущей воды (4 у стоячей), 256 SU |
| **Рукоятка** | источник: нажмите — 5 секунд вращения, 32 об/мин, 256 SU |
| **Печной двигатель** | ставится лицом к горящей печи: 16 об/мин, 1024 SU |
| **Мельница** | положите в неё сырую руду / пшеницу / булыжник (нажатием с предметом в руке); пустой рукой — забрать продукты. Руда → дроблёная руда (+50 % шанс второй), пшеница → мука, булыжник → гравий → песок |
| **Механический пресс** | над **Депо**: бросьте слиток на депо — получите лист (железо, золото, медь, латунь, цинк) |
| **Механический смеситель** | над **Чашей**: бросьте в чашу медь + цинк → 2 латуни; мука + ведро воды → тесто; андезит + железный самородок → андезитовый сплав |
| **Механический бур** | ломает блок перед собой и бьёт мобов |

Нагрузка: каждая машина создаёт нагрузку = её сложность × скорость. Если нагрузка больше суммы SU источников — сеть «перегружена» и останавливается. Нажмите **гаечным ключом** (или пустой рукой) по любому кинетическому блоку, чтобы увидеть скорость и нагрузку.

### Автоматизация
| Блок | Что делает |
|---|---|
| **Шахтная буровая** | копает шахту 3×3 прямо вниз (до Y = −60), всё добытое складывает в сундук/бочку рядом с собой |
| **Туннельный проходчик** | прокладывает ровный туннель 3×3 на 64 блока вперёд, заделывает дыры в полу булыжником и ставит факелы |
| **Логистический узел** | забирает предметы из сундука за собой и телепортирует в связанный контейнер (до 48 блоков). Связка: нажмите ключом по узлу, затем ключом по целевому сундуку |
| **Перерабатывающий завод** | берёт предметы из сундуков по бокам, переплавляет руду и дроблёную руду в слитки, брёвна → доски → палки, и крафтит железные/каменные инструменты и факелы в сундук **перед собой**. Ключом переключается режим: авто / только переплавка / только инструменты |

Пример цепочки: *буровая → сундук → логистический узел → входной сундук завода → завод → выходной сундук с инструментами*.
Тяжёлые машины (буровая, проходчик, завод) требуют 16 SU на оборот — рукоятки не хватит, нужен печной двигатель или водяное колесо.

### Руды и материалы
Цинковая руда (обычная и глубинносланцевая) генерируется в обычном мире. Цинк + медь → латунь (в смесителе). Из андезита и железных самородков — андезитовый сплав, основа всех механизмов.

### Поселенцы (самостоятельная цивилизация)
Яйцо призыва **«Поселенец»** в творческом инвентаре. Первый поселенец основывает поселение, остальные в радиусе 48 блоков присоединяются (поселений может быть до 8).

* **Роли** назначаются автоматически: строитель (жёлтая каска), добытчик (коричневая), фермер (зелёная), воин (серый шлем, железный меч). Цвет одежды — цвет клана.
* **Добытчики** рубят деревья и ищут руду рядом с поселением, а также копают шахту-карьер у ратуши. Часть добычи кладут в сундук ратуши.
* **Строители** сами возводят здания: ратуша → ферма → дома → колодец → башня → склад → стена вокруг поселения. Если дерева нет (пустыня), строят из камня/песчаника.
* **Фермеры** ухаживают за фермой; еда → рост населения (новые поселенцы рождаются у ратуши, вместимость зависит от числа домов).
* **Воины** защищают от монстров, а при войне идут походом на вражеское поселение.
* **Эпохи:** поселение развивается от Стоянки к Деревне, Городу и Индустриальному городу: новые здания (кузница, рынок, казармы, библиотека, мастерская), дороги, перестройка старых домов в новом стиле, лучшее снаряжение и ускоренная добыча.
* **Дипломатия:** отношения между кланами меняются со временем (близкие соседи напряжённее). При сильной вражде — война (сообщение в чат), через несколько минут — мир и дань проигравшего. При дружбе — союз и обмен ресурсами.
* Нажмите по поселенцу, чтобы увидеть ресурсы, население и отношения его поселения.

Подробное пошаговое руководство (постройка шахты, туннеля, завода, логистики): **[docs/GUIDE.md](docs/GUIDE.md)**.

## Крафты (основные)
* Андезитовый сплав: андезит + железный самородок (2×2 в шахматном порядке) → 2
* Вал: 2 сплава вертикально → 8
* Шестерня: вал + доски; Большая шестерня: вал + 2 доски
* Водяное колесо: доски по кругу, вал в центре
* Рукоятка: 3 доски сверху, вал справа снизу
* Андезитовый корпус: сплав + бревно; Латунный корпус: латунь + бревно
* Мельница: шестерня над камнем; Пресс: вал / корпус / железный блок; Смеситель: вал / корпус / венчик
* Бур: железные листы вокруг корпуса, вал снизу; Печной двигатель: латунные листы, печь в центре, вал снизу
* Депо: сплав над корпусом; Чаша: сплавы буквой U
* Ключ: золотой лист + шестерня, палка; Очки инженера: латунные листы + стеклянные панели
* Шахтная буровая / Проходчик / Завод / Логистический узел — см. `packs/Mechanica_BP/recipes/`

## Сборка из исходников
```
python3 tools/build.py
```
Генерирует текстуры, модели, JSON блоков/предметов/рецептов/сущностей, языковые файлы и `dist/Mechanica.mcaddon`. Скрипты лежат в `packs/Mechanica_BP/scripts/`.

## Ограничения
* Логика проверялась офлайн на эмуляции Script API, в игре аддон не прогонялся: возможны мелкие расхождения с конкретной сборкой 1.21.x (имена состояний, повороты моделей).
* Регистр кинетических блоков хранится в свойствах мира (~2000 блоков на измерение).
* Поселенцы работают, только когда их чанки загружены (игрок рядом).
